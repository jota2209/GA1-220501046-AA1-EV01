- ![](/images/software.svg) ![](/images/code.svg)
**Software:** componentes lógicos
para realizar tareas

    - **Software de Sistema:** para control y gestión
    de recursos de cómputo ejemplo: Sistemas 
    Operativos
    - **Software de aplicación:** para actividades 
    específicas y manejo de información.
    - **Software de Programación:** comunicación con la
    máquina y desarrollo de software

- ![](/images/internet.svg) ![](/images/world.svg)
**Internet**: surgió primeramente 
para conectar ordenadores 
y facilitar investigación,
    - 1969: ARPA crea protocolo TCP/IP para
    conectar ordenadores
    - 1972: primera demonstración pública de
    ARPANET, se crea primer programa de email
    - 1983: adopción de TCP/IP como base
    técnica para el funcionamiento de internet.
    - 1989: Tim Berners Lee propone WWW para
    organizar la información mediante hipervinculos
    - 1990: creación del primer navegador y servidor
    web, se descontinúa ARPANET.
    - 1993: Mosaic como primer navegador gráfico
    popular impulsando masivamente la web
    - 1994-1995: Surge Yahoo y tienda online como
    Amazon
    - 1998: Lanzamiento de Google
    - 2004: Auge de las redes sociales, nace 
    Facebook
    - 2007: Apple lanza primer Iphone, impulsando
    internet móvil
    - 2010 - 2019: crecimiento de la nube, streaming
    ecommerce
    - 2020 - 2025: avances en 5g, IA, IoT; acceso
    global a internet.

**Ofimática(Oficina + Informática):** herramientas
enfocadas en facilitar y automatizar tareas de 
oficina
    - Procesadores de texto: redacción de 
    documentos como word
    - Gestores de bases de datos: consultar y
    almacenar grande volúmenes de información
    - Herramientas colaborativas: para facilitar
    trabajo en equipo como Microsoft 365
    - Presentaciones electrónicas: creación
    de diapositivas
    - Hojas de cálculo: organizar datos,
    realizar cáculos y análisis
    (Ej. Excel y Google Sheets)
    - email y agendas electrónicas: para
    comunicación y organización de tareas
